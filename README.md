## ✨ Features

- ⚡ **Neon splash screen** — animated logo with pulsing rings
- 🖼️ **Two qualities** — Full HD (1280×720+) and 360p, with automatic fallback
- 📋 **Copy Title** — grabs the full video title in one tap
- 📝 **Copy Description** — copies the complete video description
- 🔗 **Every link format** — `watch?v=`, `youtu.be`, Shorts, embed, live, or a bare video ID
- 💾 **Saves to** `Downloads/ThumbGrab/` with a download notification
- 🚫 **No API key, no login, no ads**

---

## 📥 Install

1. Open the [**Actions**](https://github.com/XRI-DOUBLE07/ThumbGrab/actions) tab
2. Click the latest green ✅ run
3. Download **ThumbGrab-APK** from Artifacts
4. Extract the zip and install `app-debug.apk`

> Enable "Install unknown apps" for your file manager when prompted.

---

## 🛠️ Build it yourself

Open in Android Studio and hit Run, or from the command line:

```bash
gradle assembleDebug
```

Output: `app/build/outputs/apk/debug/app-debug.apk`

Every push to `main` triggers an automatic APK build via GitHub Actions.
